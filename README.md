# Command Center

Gino's personal command center: goals, money, reflections and (soon) calendar, tasks and focus points in one private dashboard.

Next.js on Vercel, Supabase for data and login. Design: Command Center design system (midnight blue and antique gold).

Environment variables: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
